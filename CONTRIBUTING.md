# Contributing

1. Keep hardware-specific defaults configurable.
2. Do not commit credentials, full flash backups, or recorded voice samples.
3. Run the native tests before opening a pull request.
4. Build with `pio run -e esp32s3_n16r8`.
5. Describe which parts were tested on real hardware and which were only
   compiled.
6. Do not add a license file or relicense the project without maintainer
   approval.
